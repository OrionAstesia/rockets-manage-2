# 最小系统规格（v1）

> **这是开发唯一需要读的文档。** 其他所有文档（`docs/archive/`）都已作废，只作历史参考。
> 阅读顺序：本文全部读完 → 开始写代码。不需要看别的东西。

**目标**：4 个 app、11 张平表、无 JS/AJAX、无多态外键、无嵌套 FormSet、无 1:1 继承。
**写操作全部走 Django Admin**（白送，不算复杂度）；前台只 3 个只读页面。

---

## 1. 一句话需求

记录 KSP 里造过的火箭与载荷、发射场、在轨航天器，安排并记录发射。附带算出火箭的 Δv 和航天器的轨道周期。

## 3. 硬性约束（违反即为偏离规格）

1. **不写任何 JavaScript**。不用 `<script>`，不用 AJAX，不用动态表单。
2. **不用嵌套 FormSet**。级用 Admin 内联管理，前台不提供级的编辑界面。
3. **不用多态外键**。不用 `GenericForeignKey`，不用 `owner_type` + 双可空 FK，不用「恰好一个非空」的 CHECK。
4. **不用 1:1 继承**。燃料罐/引擎/科学设备是**三张各自独立的表**，允许少量重复列。
5. **前台无写操作**。所有增删改在 `/admin/`。前台只有 3 个只读页面。
6. **不用裸 SQL**。只用 ORM。
7. **不引入 `requirements.txt` 之外的依赖**。

**★ `stage_order` 方向约定（全项目唯一权威）**

| | 约定 |
|---|---|
| `stage_order = 1` | **最先点火、最下面那一级**（起飞级） |
| 递增 | 向上递增，最大值 = 最上一级 |
| **渲染** | 按 `stage_order` **降序**自上而下显示（最上级在顶部），页面上必须写一行方向提示 |
| **Δv 计算** | 从 `stage_order = 1` 起**升序**累加；算第 1 级时 `m0` 要含**上方所有级 + 载荷** |

> 依据：与 KSP 内建堆栈分离组一致（空格键触发的第一个分离事件就是「第 1 级」）。
> 升序计算 + 降序渲染并存是**有意的**，但**这是本项目最容易弄反的地方**，必须有单测卡住。

**`craft_type` 与 `situation` 的区别（不要混用）**：

| 枚举 | 回答的问题 | 会变吗 |
|---|---|---|
| `craft_type` | 这是**什么东西**（空间站 / 中继卫星 / 探测器…） | 基本不变 |
| `situation` | 它**现在在干什么**（环绕中 / 已着陆 / 逃逸中…） | 会随任务变化 |

> 例：一个探测器（`craft_type=PROBE`）可能先是 `ORBITING`，着陆后变 `LANDED`。

**校验（`clean()`）**：
- `sma` 非空时必须 `> body.radius`，错误提示写明「半长轴不是高度」
- `situation` 为 `ORBITING` 且 `eccentricity` 非空时，要求 `0 <= e < 1`
- `inclination` 非空时要求 `0 <= inclination <= 180`

**`sma` 与高度的区别（界面必须提示）**：`sma` 是**天体中心到轨道的距离**（半长轴）；高度 = `sma − Body.radius`。Kerbin 半径 600 km，混淆两者会产生 600 km 量级的错误。表单 `help_text` 必须写明，例如：
`半长轴（天体中心到轨道），不是高度。Kerbin 半径 600 km，所以 100 km 高的圆轨道 sma = 700000。`

**派生量不落库**：周期、近拱点、远拱点一律实时计算（§7）。`cached_period_sec` 是玩家从 MechJeb/KER 抄录的快照，仅用于「计算值 vs 录入值」对照展示。

```python
class GameMode(models.TextChoices):

    SCIENCE = "SCIENCE", "科研模式"
    SANDBOX = "SANDBOX", "沙盒模式"
```

`Meta.ordering = ["name"]`

**`Save` 是 1:n 的「1」端**：`Rocket.save` / `Payload.save` / `Site.save` / `Spacecraft.save` / `FlightLog.save` **五个普通外键**指向它 —— **没有链接表**。

**这五个外键是必填的**（不加 `null=True, blank=True`）：每个对象都必须属于一个存档。Admin 里录入任何对象前，先建一个存档。

**`name` 上的 `unique=True` 不加 `save` 限定**（即全局唯一，不是每个存档内唯一）。理由：存档是根，玩家在不同存档里给火箭起同一个名字的概率极低，而全局唯一少一个约束、错误提示也更简单。若日后确实需要"每个存档内唯一"，再把 `unique=True` 换成 `UniqueConstraint(fields=["save", "name"])`。

**删除策略用 `CASCADE`**（与下面 §4.12 的其他关系不同）：存档是根，玩家删掉一个存档就是想清掉它里面的全部内容。

### 4.12 `on_delete` 总表

| 父 → 子 | 策略 |
|---|---|
| **`Save` → `Rocket` / `Payload` / `Site` / `Spacecraft` / `FlightLog`** | **`CASCADE`**（存档是根，删存档即清空其内容） |
| `Rocket` → `RocketStage` | `CASCADE` |
| `Engine` → `RocketStage.engine` | **`PROTECT`** |
| `FuelTank` → `RocketStage.fuel_tank` | **`PROTECT`** |
| `Body` → `Site` / `Spacecraft` | **`PROTECT`** |
| `Rocket` / `Payload` / `Site` → `FlightLog` | **`PROTECT`** |
| `FlightLog` → `Spacecraft.source_flight` | `SET_NULL` |

> **`PROTECT` 处必须在视图/Admin 捕获 `ProtectedError`**，转成 `messages.error()` 友好提示，否则用户看到 500。

```powershell

```

**幂等性**：`loaddata` 按 `pk` upsert，重复执行不会产生重复行，但**会把你手工改过的天体数值覆盖回上表的值**。若你调整过天体常数，改 fixture 或改用 Admin 录入。

## 6. 常量（`core/constants.py`）

```python
G0 = 9.80665              # 标准重力加速度 (m/s²)。Δv 公式用，与所在天体无关。
FUEL_UNIT_MASS = 0.005    # 每单位燃料质量 (t/单位)，即 1 单位 = 5 kg。
KERBIN_DAY = 21549.4      # Kerbin 恒星日 (s)。用于把「周期秒数」换算成「Kerbin 天」。
```

**`G0` 必须是常数，与天体无关。** 见 §7.2 的警示。

**`KERBIN_DAY` 必须是 21549.4（恒星日），不是 21600（太阳日）。** 用 21600 反算同步轨道会得 2868.75 km，正确值是 2863.33 km。它不是 UT 时间戳，与是否记录游戏时间无关。

## 7. 计算（`services/orbital.py`，只有 7 个函数）

**这是唯一的 services 文件。** 纯函数，只接受数字，不 import Django。

```python
import math
from core.constants import G0, FUEL_UNIT_MASS, KERBIN_DAY


def orbital_period(sma, eccentricity, mu):
    """轨道周期。返回 (秒, Kerbin天数)；不可计算时返回 (None, None)。"""
    if sma is None or mu in (None, 0):
        return None, None
    if eccentricity is not None and eccentricity >= 1:
        return None, None          # 双曲线/抛物线轨道无周期
    if sma <= 0:
        return None, None
    seconds = 2 * math.pi * math.sqrt(sma ** 3 / mu)
    return seconds, seconds / KERBIN_DAY


def apsis(sma, eccentricity):
    """(近拱点半径, 远拱点半径)，米。sma 为空返回 (None, None)。"""
    if sma is None:
        return None, None
    e = eccentricity or 0.0
    return sma * (1 - e), sma * (1 + e)


def altitude(r, body_radius):
    """半径 → 相对天体表面的高度 (m)。"""
    if r is None or body_radius is None:
        return None
    return r - body_radius


def stage_dry_mass(stage):
    """一级的干重 (t) = 引擎干重×数量 + 燃料罐干重×数量 + 结构质量。"""
    m = stage.structure_mass or 0.0
    if stage.engine_id and stage.engine:
        m += (stage.engine.dry_mass or 0.0) * (stage.engine_count or 0)
    if stage.fuel_tank_id and stage.fuel_tank:
        m += (stage.fuel_tank.dry_mass or 0.0) * (stage.tank_count or 0)
    return m


def stage_fuel_mass(stage):
    """一级的燃料质量 (t) = 容量 × 数量 × FUEL_UNIT_MASS。"""
    if not (stage.fuel_tank_id and stage.fuel_tank):
        return 0.0
    return (stage.fuel_tank.capacity or 0.0) * (stage.tank_count or 0) * FUEL_UNIT_MASS


def stage_delta_v(stage, upper_mass):
    """单级 Δv (m/s)。

    upper_mass: 该级上方所有级的总质量 + 载荷质量 (t)。
    isp 选择：stage_order == 1 用 isp_asl，其余用 isp_vac。
    引擎/比冲缺失时返回 None。
    """
    if not (stage.engine_id and stage.engine):
        return None
    isp = stage.engine.isp_asl if stage.stage_order == 1 else stage.engine.isp_vac
    if not isp:
        return None
    fuel = stage_fuel_mass(stage)
    if fuel <= 0:
        return None
    dry = stage_dry_mass(stage)
    m0 = upper_mass + dry + fuel
    mf = upper_mass + dry
    if mf <= 0 or m0 <= mf:
        return None
    return isp * G0 * math.log(m0 / mf)


def vehicle_delta_v(rocket, payload_mass=0.0):
    """整枚火箭的逐级 Δv。

    返回 [{"stage_order", "m0", "mf", "fuel_mass", "delta_v", "cumulative"}, ...]
    按 stage_order **升序**排列。
    """
    stages = list(rocket.stages.order_by("stage_order"))
    upper = payload_mass or 0.0
    result = []
    for stage in reversed(stages):           # ★ 自最上级向下递推
        fuel = stage_fuel_mass(stage)
        dry = stage_dry_mass(stage)
        m0 = upper + dry + fuel
        dv = stage_delta_v(stage, upper)
        result.append({
            "stage_order": stage.stage_order,
            "m0": m0,
            "mf": upper + dry,
            "fuel_mass": fuel,
            "delta_v": dv,
            "cumulative": None,              # 下面填
        })
        upper = m0                           # ★ 本级点火质量成为下一级的 upper
    result.reverse()                         # 转回升序
    total = 0.0
    for row in result:
        if row["delta_v"] is not None:
            total += row["delta_v"]
            row["cumulative"] = total
    return result
```

### 7.1 `m0` 必须包含上方所有级 + 载荷（最容易算错的地方）

火箭是叠罗汉。最下面一级点火时，必须把它**上面的一切**都推上去。

**错误**：`m0 = 本级干重 + 本级燃料`（漏了上方）
**正确**：`m0 = 本级干重 + 本级燃料 + 上方各级总质量 + 载荷质量`

上面代码用 `reversed()` 自最上级递推实现，`upper` 逐级累加。

**质量闭合校验**（写进单测，是发现「漏算某一级」的最有效手段）：

```
vehicle_delta_v(...)[-1]["m0"]  ==  所有级干重之和 + 所有级燃料之和 + 载荷质量
```

### 7.2 ⚠️ Δv 用 `G0` 常数，不用当地重力（无声 bug）

比冲的定义是 $I_{sp} \equiv F/(\dot m\,g_0)$，$g_0$ 是**定义该单位时约定的常数 9.80665**，不是环境属性。

| 用哪个 g | `isp=345, m0/mf=2.5` | 偏差 |
|---|---|---|
| ✅ `G0 = 9.80665` | **3100.08 m/s** | 基准 |
| ❌ Kerbin 表面 `9.81` | 3101.14 m/s | +0.03%（**在母星上测试永远发现不了**） |
| ❌ Mun 表面 `1.63` | 515.28 m/s | **−83%** |

**防护**：`stage_delta_v()` 的签名里**不出现任何 `g` / `gravity` / `body` 参数** —— 物理上无法传错。并加一条负例断言（见 §9）。

### 7.3 ⚠️ `sma` 不是高度

`sma` 是**天体中心到轨道**的距离。高度 = `sma − Body.radius`。
Kerbin 半径 600 km ⇒ **100 km 高的圆轨道 `sma = 700000`**。

### 7.4 周期与「天」的换算

`T = 2π√(a³/μ)`，只用到 `Body.mu` 与 `sma`。
「Kerbin 天」= `T / 21549.4`，界面文案必须写明是 **Kerbin 天**。

参考值：Kerbin 100 km 圆轨 `sma=700000` → `T = 1958.13 s = 0.0909 Kerbin 天`。

`/rockets/<int:pk>/` 的视图实现：

```python
class RocketDetailView(DetailView):
    model = Rocket
    template_name = "fleet/rocket_detail.html"

    def get_context_data(self, **kwargs):
        ctx = super().get_context_data(**kwargs)
        ctx["stage_rows"] = vehicle_delta_v(self.object)          # 已按 stage_order 升序
        ctx["total_dv"] = sum(r["delta_v"] or 0 for r in ctx["stage_rows"])
        return ctx
```

模板里**降序渲染**：`{% for row in stage_rows reversed %}`，并写方向提示：
`ℹ 本页自上而下显示，底部为第 1 级（最先点火的起飞级）。Δv 从第 1 级起向上累加。`

前台**不提供任何表单**。`base.html` 的导航只放这 3 个页面 + 一个指向 `/admin/` 的链接。
