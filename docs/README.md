## 一句话概括要做什么

| 需求 | 落地 |
|---|---|
| 燃料罐 / 引擎 / 科学设备表 | `parts` app 的 4 张表（含超类 `PartCatalog`） |
| 火箭 / 载荷的级结构（1 火箭 n 级，1 级 n 燃料罐或引擎） | `Stage` + `StageTank`（单表多态，火箭与载荷共用） |
| 发射计划与日志 | `FlightLog`（`planned_ut` 与 `actual_ut` 分离） |
| 航天计划（1 计划 : n 对象） | `Program` + `ProgramLink` |
| 在轨航天器（轨道与周期信息） | `Spacecraft`（`sma` 为权威输入，周期为派生值） |
| 附带 | Δv 与推重比计算、发射日程视图 |

---

## 三个最容易出错的地方（详见 `spec/01` §5）

1. **`stage_order` 方向**：`1` = 最先点火的最下面一级；页面**降序**渲染，Δv **升序**累加
2. **`sma` 不是高度**：高度 = `sma − Body.radius`（Kerbin 600 km）
3. **多态 FK 不用 `GenericForeignKey`**：用 `owner_type` + 双可空 FK + CHECK
