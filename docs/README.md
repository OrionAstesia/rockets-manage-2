## 为什么这么小

细节越多，代码越复杂，实现越容易偏离规格。所以：

- **砍掉了所有多态设计**：级直接挂火箭（不再用 `owner_type` + 双可空 FK）；航天计划的成员用 3 个普通外键，不用链接表
- **砍掉了 1:1 继承**：燃料罐 / 引擎 / 科学设备是三张独立平表（允许少量列重复）
- **砍掉了所有 JS 与嵌套 FormSet**：级在 Admin 里用 `TabularInline` 管
- **砍掉了 KSP 游戏时间**：所有时间用真实日期 `DateField`

留下的只剩你提的 6 项需求本身。
